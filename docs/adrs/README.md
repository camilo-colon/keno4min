# Architecture Decision Records (ADRs)

Este directorio documenta decisiones de arquitectura que tienen consecuencias
importantes o difíciles de revertir a largo plazo.

## Convención

- Nombre: `NNNN-titulo-breve.md` (por ejemplo,
  `0003-usar-amazon-dynamodb-como-base-de-datos-principal.md`).
- Estados sugeridos: `Propuesta`, `Aceptada`, `Rechazada`, `Obsoleta` o
  `Reemplazada`.
- Una decisión aceptada no se elimina: si cambia, se crea un nuevo ADR que la
  reemplace y se enlazan ambos documentos.

Para registrar una decisión, copia [template.md](template.md), asígnale el
siguiente número disponible y completa sus secciones.
